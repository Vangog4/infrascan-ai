### Новый `_QC_PROMPT` — 4 критерия по 25 баллов
| Критерий | Что проверяется |
|---|---|
| ЧЁТКОСТЬ | Резкость, отсутствие смазанности и дрожания |
| ОСВЕЩЁННОСТЬ | Экспозиция; для тепловизора — видимость шкалы температур |
| ПОЛНОТА КАДРА | Объект целиком, правильный угол, объект — главный в кадре |
| РЕЛЕВАНТНОСТЬ | Это строительный/инженерный объект? |

### Три уровня вердикта
- **ПРИНЯТО** (≥70/100) → 🟢 — всё отлично
- **ЗАМЕЧАНИЕ** (50–69/100) → 🟡 — принято, но инженер видит замечание
- **БРАК** (<50/100) → ❌ — пересъёмка, конкретный совет что исправить

### `check_quality()` — новый интерфейс
```python
# Было:
ok, reason = await gemini.check_quality(photo_bytes)  # tuple[bool, str]

# Стало:
qc = await gemini.check_quality(photo_bytes)
# {ok, score, verdict, reason, tip, object}
```
