## Новый проект: `/root/Polygon/` — ERP для «ШМАЛЯЙ»

Параллельно с infrascan-ai поднят отдельный Odoo 19 стек для нового проекта **«ШМАЛЯЙ»** — система умных тактических мишеней с AI-скорингом (YOLOv8) и локальным LLM-тренером «Михалыч».

### Инфраструктура (podman-compose)
- Контейнер `odoo_polygon_app` — Odoo 19 Community, порт `127.0.0.1:8075:8069` / `8077:8073`
- Контейнер `odoo_polygon_db` — Postgres 17, внутренняя сеть `polygon_net` (172.30.0.0/24)
- База данных: `odoo_user_pepito` (через MCP сервер), odoo user: `vangog4@gmail.com`
- MCP сервер: FastMCP 3.2.4, логи → `infrascan-ai/logs/mcp_server_stdio_*.log`

### Модули Odoo (addons/)

#### `polygon_core` v1.0.0
- Базовый модуль, абстрактная модель `polygon.base` (name + active)
- Главное меню Polygon в Odoo UI
- Зависимость: `base`

#### `polygon_crm` v1.0.0
- Наследует `crm.lead`, добавляет поля:
  - `polygon_lead_type` — Selection: technical / commercial / strategic
  - `polygon_estimated_value` — Monetary
- View: поля вставлены после `team_id` в форму лида
- Был баг: `IndexError` при установке из-за пустого `ir.model.access.csv` в манифесте — исправлено удалением пустого файла

#### `shmalyai_core` v1.0.0
- Наследует `product.template`, добавляет:
  - `shmalyai_device_type` — Edge Node (ESP32) / Central Hub (RPi) / Accessory / Software
  - `shmalyai_hardware_rev` — ревизия железа
  - `shmalyai_firmware_version` — версия прошивки
  - `shmalyai_sensor_type` — vibration / acoustic / optical / mixed
  - `shmalyai_is_kit` — флаг комплекта
- Data: предзаполненные продукты в `product_data.xml`
- Зависимости: `product`, `polygon_core`

#### `shmalyai_mrp` v1.0.0
- BoM для комплектов: **Старт**, **Движ**, **Штурм**, **Нейро**
- Зависимости: `mrp`, `shmalyai_core`

#### `shmalyai_sales` v1.0.0
- Ценообразование B2B / B2C / B2G
- Подписочные модели для AI-фич и OTA-обновлений
- Зависимости: `sale_management`, `shmalyai_core`

#### `shmalyai_fleet` v1.0.0
- Новая модель `shmalyai.device` — IoT fleet management:
  - Serial/ID, product, device_type, owner/partner
  - Status: online / offline / maintenance / retired
  - last_ping, firmware_version, hardware_rev, ip_address, mac_address
  - `mail.thread` + `mail.activity.mixin` — отслеживание изменений
- Зависимости: `shmalyai_core`
- Назначение: мониторинг MQTT, планирование OTA-обновлений

#### `shmalyai_website` v1.0.0
- Лендинг для e-commerce, чёрный/красный брендинг (MIL-SPEC стиль)
- Секции: Hero, Outcomes (3.5x скорость / -40% боеприпасы / 100% объективность), Features (YOLOv8 / Mesh-сеть / BPLA training), Partners, Targets, Coach («Михалыч»), Global CTA
- Главная страница переопределена на `/` через `website.page`
